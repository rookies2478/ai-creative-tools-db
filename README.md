# ai-creative-tools-db

AIクリエイティブナビ（AI画像生成・動画生成ツール比較DB）のAstroサイト。

## 正式運用文書

- 方針判断: 計画書 Ver2.0（検索流入立ち上げ・DB品質・独自検証 統合版）
- 作業手順: 運用ルール Ver4.0（GitHub共有コンテキスト・構造化タスク・GSC/Clarity統合版）
- 詳細は [docs/decisions/current-governance-documents.md](docs/decisions/current-governance-documents.md) を参照。

## 開発

```
npm run dev
npm run build
npm run preview
```

## タスク運用

- 進行中タスク: `docs/tasks/active/`
- 完了タスク記録: `docs/tasks/completed/`
- 最新状態: `docs/tasks/LATEST.md`
- タスク検証: `npm run validate:task`
- 変更範囲検証: `npm run validate:scope`
