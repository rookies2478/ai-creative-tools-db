# 新規ツール登録時の公式日本語・料金・アフィリエイト確認ルール

確認順序：日本語公式サイト→日本語料金・規約→英語公式補足→紹介制度・成果条件→当サイトの承認状態→公開情報記録。

1. 日本語公式製品URL（同一提供事業者の公式ドメイン）を最初に探索。日本語公式ドキュメントと日本語Web UIを別分類し、見つからなければ未特定と記録する。
2. 日本向け料金表を優先し、Free/Trial、月払い実額、年払い月換算、クレジット・透かし・商用権利差、税・通貨、対象モデルを区別。日本語ページがUSD表記なら円換算を勝手に公式価格として掲載しない。公式内部価格差やJS動的価格はHOLD。
3. 有料契約を結べば無制限に商用可能とは断定しない。無料・有料・法人/受託/広告用途と第三者素材の権利を分ける。
4. 公式サイト内のAffiliate/Partner/Referral/Creator/Ambassadorを必ず調査。現金報酬、紹介クレジット、申請ポータルのみ、第三者ASPのみ、未発見を区別して公式根拠URLを保存。料率、Cookie、対象プラン、支払手段、最低支払額、トラフィック制限を記録。
5. **日本の検索流入が成果対象か必ず確認**。例：Pixelcutは公式規約で主要検索エンジン由来のクリックを成果対象外と明記。料率30%だけで高収益ツールと評価しない。
6. 公式提携制度の存在と当サイトの契約・審査合格・専用リンク取得・日本への支払可能性は別管理。専用承認済みURLがない限りaffiliateUrlを追加・変更しない。
7. 全件の公開根拠と確認日を更新し、公式レジストリ、DB正本、アフィリエイト監査表の整合を検証。画質や機能実測は実機作例がある場合だけ主張する。
